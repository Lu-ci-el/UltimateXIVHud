# UltimateXIVHud (UXHD)

[日本語](README.md)

Share FFXIV through OBS, Discord or Discord PTB while keeping supported external overlays out of the captured image. The overlays remain visible on your own screen, and the game's normal HUD remains in the stream.

## Download

[Download the latest version](https://github.com/Lu-ci-el/UltimateXIVHud/releases/download/v0.4.5.8/UltimateXIVHud_0.4.5.8.zip)

**Requirements:** Windows x64, DirectX 11 FFXIV, and .NET 8 Desktop Runtime (x64).

## Getting started

1. Extract the entire ZIP into a writable folder of your choice.
2. Run `UltimateXIVHud.exe`. You can start UXHD before or after FFXIV.
3. Wait for the automatic connection, then select FFXIV in OBS Game Capture or in Discord / Discord PTB game or window sharing.
4. Check both the preview and the actual stream before using it.

Use **日本語 / English** at the top of the window to change the language.

While the app is waiting, let the game finish starting. If the app asks you to restart FFXIV, restart the game.

To update, extract the entire new ZIP into a separate folder. Do not run the app from inside the ZIP or mix files from different versions.

## Use and streaming

**Please use and stream at your own risk.** Compatibility depends on your environment. Before streaming, confirm that viewers see the image you intend to share.

UXHD covers OBS Game Capture and Discord / Discord PTB previews and live sharing. Desktop-wide capture is not covered.
