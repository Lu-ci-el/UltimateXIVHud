# UltimateXIVHud（UXHD）

[English](README.en.md)

FFXIVをOBS・Discord・Discord PTBで共有するときに、対応する外部オーバーレイを配信映像から除くアプリです。自分のゲーム画面では表示したまま使えます。ゲーム本来のHUDは配信映像にも残ります。

## ダウンロード

[最新版をダウンロード](https://github.com/Lu-ci-el/UltimateXIVHud/releases/latest)

**必要な環境：** Windows x64、DirectX 11版FFXIV、.NET 8 Desktop Runtime（x64）。

FF14のバージョンアップがくると使えなくなります。

## 使い方

1. ZIPを、書き込みできる好きなフォルダーへすべて解凍します。
2. `UltimateXIVHud.exe`を管理者として起動します。FFXIVとUXHDは、どちらを先に起動しても使えます。
3. 自動接続を待ち、OBSのゲームキャプチャ、またはDiscord・Discord PTBのゲーム／ウィンドウ共有でFFXIVを選びます。
4. プレビューと実際の配信映像を確認してから使ってください。

画面上部の **日本語 / English** で言語を切り替えられます。

設定で次の2項目を選べます（初期値はOFF）。

- **Windows起動時に自動起動**：本人のログオン時に管理者権限で起動します。登録・解除の際は、UXHDを管理者として起動してください。
- **起動時にタスクトレイへ収納**：起動時からトレイに収納します。トレイアイコンのダブルクリックで画面を戻せます。

別フォルダーの新版へ切り替えるときは、新版で自動起動をいったんOFF→ONにして、登録先を更新してください。

接続待ちの間は、ゲームの起動完了を待ってください。再起動を求める表示が出た場合は、FFXIVを再起動してください。

更新するときは、新しいZIPを別のフォルダーへすべて解凍してください。ZIP内からの直接起動や、異なる版のファイルの混在は避けてください。
