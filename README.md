# UltimateXIVHud（UXHD）0.4.9.6

[English](README.en.md)

FFXIVをOBS・Discord・Discord PTBで共有するときに、GShadeを配信映像に映さないためのアプリです。自分のゲーム画面ではGShadeを表示したまま使い、ゲーム本来のHUDは共有映像に残します。

## ダウンロードと環境

[最新版をダウンロード](https://github.com/Lu-ci-el/UltimateXIVHud/releases/latest)

Windows x64、DirectX 11版FFXIV、.NET 8 Desktop Runtime（x64）が必要です。

この公開版はFFXIVパッチ7.58用です。FF14のバージョンアップ後は使用できなくなります。

## 使い方

1. ZIPを、書き込みできる好きなフォルダーへすべて解凍します。
2. **UXHDを管理者権限で起動**します。
3. できるだけ **UXHD → FF14 → Discord（通常／PTB）** の順に起動し、UXHDの接続を待ってから配信を開始してください。0.4.9.1の実機確認では、この順序で表示までの待ち時間が短くなりました。
4. Discordでは、**FFXIVを直接共有対象に選択すればゲーム音声も共有できます**。OBSではゲームキャプチャにFFXIVを指定してください。**OBSの起動順は問いません**。
5. プレビューと実際の配信映像の両方で、見せたい映像が正しく共有されていることを確認してください。

配信中にUXHDを後から起動した場合、既に取得した映像が切り替わらず、**配信を停止して再開する必要がある場合があります**。クリーンな映像の準備中は黒くなり、準備後に表示へ戻ることがあります。復帰時間は保証していません。

画面上部の **日本語 / English** で言語を切り替えられます。

設定で次の2項目を選べます（初期値はOFF）。

- **Windows起動時に自動起動**：本人のログオン時に管理者権限で起動します。登録・解除の際は、UXHDを管理者として起動してください。
- **起動時にタスクトレイへ収納**：起動時からトレイに収納します。トレイアイコンのダブルクリックで画面を戻せます。

最小化でのトレイ収納や、自分で設定した表示・収納ショートカットも利用できます。

別フォルダーの新版へ切り替えるときは、新版で自動起動をいったんOFF→ONにして登録先を更新してください。更新時は新しいZIPを別フォルダーへすべて解凍し、ZIP内からの直接起動や異なる版のファイル混在を避けてください。

## 確認範囲と配信利用

0.4.9.6では、7.58のゲーム本体を識別できることをオフラインで確認しました。**7.58にログインした状態での動作と配信映像は未確認です。** 通常Discord・Discord PTBの配信映像にGShadeが映らないことを実機で確認したのは0.4.9.1です。

**利用・配信は自己責任でお願いします。** 環境や起動順で動作が変わる場合があります。配信前にプレビューと実配信を確認してください。対象はOBSゲームキャプチャと通常Discord・Discord PTBの共有で、デスクトップ全体のキャプチャは対象外です。
